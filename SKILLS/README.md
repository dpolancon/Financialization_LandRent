# Land-Rent Systematic Review Artifact Bundle

This bundle contains a first-pass orchestration system for turning `Financialization_LandRent/notes/questions` into a theory-led systematic narrative review.

Files:

- `SYSTEMATIC_REVIEW_ORCHESTRATOR.md`: full workflow, review question, extraction dimensions, quality gates, and draft architecture.
- `SKILL_SYSTEMATIC_REVIEW_LANDRENT.md`: reusable skill for Codex/agentic use over the repo.
- `review_matrix_schema.csv`: starting extraction matrix schema.
- `codex_prompt_bootstrap.md`: prompt to run inside the local repository.
