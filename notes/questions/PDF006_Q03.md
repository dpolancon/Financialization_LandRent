## NotebookLM question

What is the difference between phase transitions and state transitions?

## NotebookLM answer

> [NOTEBOOKLM] In the provided framework, phase transitions and state transitions describe two fundamentally different types of macroeconomic shifts. A phase transition is an *endogenous* change along an economy's dynamic trajectory where the endogenous state variable (the capital stock, $k_t$) crosses a threshold, moving the economy from a regime with a unique momentary equilibrium into one with multiple momentary equilibria, or vice versa [1, 2]. Because it is endogenous, a phase transition occurs naturally as part of the economy's wobbly fluctuations. By contrast, a state transition is an *exogenous* structural shift caused by a change in a deep macroeconomic parameter, such as labor productivity [1, 3]. When such a parameter reaches a critical point, it induces a state transition that fundamentally alters the entire system's structural stability and the set of feasible global dynamics, for example by suddenly transforming a stable economic boom into a fragile, unstable one [1, 4].

## Distilled note

- **Core claim**: Phase transitions are endogenous dynamic movements between unique and multiple equilibrium regimes along a given trajectory, whereas state transitions are exogenous structural shifts caused by parameter changes that redefine the macroeconomic system's overall stability.
- **Mechanism**:
  - As the endogenous capital stock ($k_t$) evolves over time, it may cross specific mathematical boundaries ($\underline{k}$ or $\overline{k}$).
  - Crossing these boundaries triggers an endogenous phase transition, abruptly shifting the economy between deterministic outcomes and expectation-driven indeterminacy.
  - Separately, an exogenous change to a fundamental parameter (such as a technological innovation or labor productivity shock) structurally shifts the underlying savings and investment mappings ($\Omega$ and $W$).
  - When this parameter crosses a critical threshold, it triggers a state transition, permanently redefining the economy's dynamic regime (e.g., shifting the economy from a state with a stable steady-state into a state characterized by an unstable boom and a stagnation trap).
- **Formal object/result, if any**: Not applicable
- **Relevance for the project memo**: critique
- **Critical caveat**: The model’s distinction between these transitions relies on a closed-economy framework where transitions are driven purely by domestic capital accumulation or domestic technological parameters; applying these exact dynamics to Latin America requires external verification regarding the region's exposure to exogenous global financial shocks, foreign debt crises, and terms-of-trade shifts.
