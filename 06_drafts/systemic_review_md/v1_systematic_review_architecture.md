# Architecture for v1 Systematic Review Draft

## Draft classification

The previous file `06_drafts/v1_systematic_review_draft.md` was classified as **salvageable fragments only**. Its broad headings overlapped with the required section architecture, but its claims were generic, the corpus description was wrong, citation placeholders were not disciplined, and it contained audit material inside the draft. The rewritten draft preserves only the broad intuition that the review should move from conceptual foundations to mechanisms, policy, and translation.

## Governing architecture

The draft follows the binding writing skill in `SKILLS/SKILL_drafting_systematic_review.md`: definition -> mechanism -> causal chain -> variables -> model result -> implication -> limitation. It expands the executive memo `01_memo_ejecutivo_V0.1/M01_memo_ejecutivo.md` rather than replacing its conceptual spine.
