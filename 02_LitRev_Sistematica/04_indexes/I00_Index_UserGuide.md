The index notes function collectively as a **relational database and workflow routing architecture** for the research project, translating a collection of raw PDFs into a structured and guided synthesis.

Here is the synthesis of their specific functionalities:

**1. The Master Directory: `I03_source_index.md`** This file acts as the central hub for document tracking and prioritization.

- **Identification:** It links abstract `Source IDs` (e.g., PDF001) to concrete metadata, including the exact `Filename`, `Title`, `Authors`, and `Year`.
- **Thematic Routing:** It categorizes papers by assigning them to a specific `Cluster` (e.g., C4, C5), grouping them by research theme.
- **Workflow Control:** It assigns a `Priority` status (e.g., High, Medium) to dictate the order in which the sources should be read and synthesized.

**2. The Macro-Level Synthesis Router: `I01_cluster_question_index.md`** This file bridges the thematic clusters to the final project deliverables by mapping `Cluster IDs` to overarching research questions.

- **Output Formatting:** It strictly defines the `Expected answer type` for each question, such as requiring a "Mechanism paragraph", a "Definition block", or a "Warning list".
- **Deliverable Targeting:** It specifies the exact `Use` for the generated answers within the project architecture, ensuring the text routes perfectly into sections like the "Core synthesis", "Literature map", or "Conceptual glossary".

**3. The Document-Level Extraction Guide: `I02_per_paper_question_index.md`** This file drills down to the micro-level, guiding the exact information extraction for each individual paper.

- **Targeted Interrogation:** It links a specific `Source ID` directly to highly specific questions tailored to that document.
- **Conceptual Tagging:** It categorizes each question with a specific `Tag`—such as "research question", "mechanism", "formal result", "policy/welfare", or "critique"—ensuring that the theoretical, empirical, and policy dimensions of each paper are systematically captured.

**Summary** Working in tandem, the sources establish a complete pipeline: `I03` identifies and groups the papers, `I02` extracts the targeted micro-level insights from those specific papers, and `I01` shapes those insights into the correct format for the macro-level project deliverables.
