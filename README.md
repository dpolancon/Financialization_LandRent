# Financialization_LandRent

This repository supports a theory-led systematic narrative review on land rent, land-price inflation, credit, financialization, unbalanced growth, land overvaluation, and debt rollover in the Hirano-Stiglitz-Toda corpus. The project translates that literature cautiously toward a Fondecyt-facing research agenda on Latin American land-rent financialization.

## Repository Layers

`00_Intakes/` is the initial intake layer. It records original prompts and early project inputs and should not be treated as active synthesis.

`01_memo_ejecutivo_V0.1/` contains the earlier brief and memo artifacts that seeded the systematic review. It remains a conceptual and Fondecyt-framing precursor layer, not the active systematic-review draft.

`02_LitRev_Sistematica/` contains the development bundle and indexes that supported construction of the repo. Use `02_LitRev_Sistematica/04_indexes/` as source-routing infrastructure. Do not treat this folder as the active note or writing layer.

`03_notes/` is the active note system:

- `03_notes/papers/` is the main reading layer.
- `03_notes/questions/` is the atomic per-paper provenance layer.
- `03_notes/clusters/` is the thematic synthesis layer.

`04_review_artifacts/` is the review infrastructure and output-control layer. It contains the extraction matrix, synthesis maps, memo architecture, expansion plan, active artifact map, and final-pass planning.

`06_drafts/` is the draft lineage and prose layer. Multiple v1 drafts are preserved for audit, so the active input draft must always be named explicitly.

`SKILLS/` is the skill toolkit layer. The active final-pass stack is the drafting skill, the Phase 3 synthesis skill, and then the editing skill.

`90_zip_files/` is an archive/source-bundle layer. Do not unpack or modify it unless a later pass explicitly asks for that.
